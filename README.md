# 🌤️ Weather App

A real-time weather application that fetches live weather data from OpenWeatherMap API.

## Features

- Search weather by any city name
- Displays current temperature
- Shows "Feels like" temperature
- Shows humidity percentage
- Shows wind speed
- Dynamic weather icons (sun, cloud, rain, etc.)
- Error handling for invalid city names

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- OpenWeatherMap API

## Live Demo

[Click here to view the live app](https://MKARUNYA27.github.io/weather-app)

## How to Run Locally

1. Clone this repository
2. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api)
3. Replace `YOUR_API_KEY_HERE` in `script.js` with your actual API key
4. Open `index.html` in your browser
